# Logger Package (`@repo/logger`)

Un utilitaire de logging simple et unifié pour l'ensemble du monorepo.

## 🚀 Utilisation

```typescript
import { logger } from "@repo/logger"

logger.info("Message informatif")
logger.error("Une erreur est survenue", error)
```

Il est conçu pour être compatible à la fois avec les environnements Node.js (Backend) et le navigateur (Frontend).
